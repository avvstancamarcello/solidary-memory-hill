## 🚀 GitHub Pages Setup

This repository is configured to work with GitHub Pages. To enable it:

### Method 1: Automatic Setup (Recommended)
1. Go to your repository settings
2. Scroll down to "Pages" section
3. Under "Source", select "Deploy from a branch"
4. Choose "main" branch and "/ (root)" folder
5. Click "Save"
6. Your site will be available at `https://yourusername.github.io/solidary-memory-hill/`

### Method 2: GitHub Actions (Alternative)
1. Go to repository settings → Pages
2. Under "Source", select "GitHub Actions"
3. The site will automatically deploy when you push changes

## 🛠️ Local Development

To run the site locally:

```bash
# Clone the repository
git clone https://github.com/avvstancamarcello/solidary-memory-hill.git
cd solidary-memory-hill

# Start a local web server
python -m http.server 8080
# or
npx http-server

# Open browser to http://localhost:8080
```

## 🎨 Customization

### Replacing the Homepage
If you have your own HTML code for the homepage:

1. **Replace content in `index.html`**: Keep the basic HTML5 structure but replace the content within the `<body>` tag
2. **Update styles in `styles.css`**: Modify colors, fonts, and layout to match your design
3. **Enhance functionality in `script.js`**: Add your own interactive features

### Key Classes and IDs
- `.hero` - Main hero section
- `.sanctuary-section` - Features section
- `.roses-section` - NFT roses section  
- `.memories-section` - Memory messages section
- `.btn.primary` / `.btn.secondary` - Button styles
